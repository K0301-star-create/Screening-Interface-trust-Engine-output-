# Screening interface: trust engine output

Desk editor screening prototype (Taylor & Francis design system).

- `screening.html`: the full prototype, one self-contained file (inline CSS and JavaScript, hash routing)
- `index.html`: opens the prototype, so GitHub Pages can serve it at the root

## What it shows
- **Dashboard:** welcome banner and "To do: screening checks", with Start screening and a progress-aware button for each submission
- **Screening page:** To screen and Already screened (filter by escalated, on hold, sent to a handling editor, rejected)
- **Screening report:** AI checks (green, amber, red), the author trust score, the manuscript and metadata viewers, and "Your decision" on the right (send to a handling editor, put on hold, escalate, reject), then a confirmation page with what happens next

Only external dependency: Google Fonts (Aleo, Open Sans).
